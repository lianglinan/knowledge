# 每日知识

一个零依赖的单文件网页，用来每天积累一点跨领域的知识，并且**真的记得住**。

直接在浏览器打开 `index.html` 就能用，不需要服务器、不需要联网、不需要构建。

## 为什么是"卡片"而不是"收藏夹"

AI 时代，可被检索的孤立事实在快速贬值。真正保值的是三件事：

1. **能讲清**（不是"看过"）
2. **能连线**（和已有知识挂上钩）
3. **能用上**（一次真实决策胜过十篇文章）

所以这里没有"待读列表"，只有一个闭环：**读一点 → 用自己的话写一张卡 → 间隔重复到能脱口而出。**

## 每天怎么用（25–35 分钟）

| 步骤 | 时间 | 做什么 |
|---|---|---|
| 输入 | 15 分钟 | 「今日」里三个输入方向挑**一个**，读完再动笔 |
| 输出 | 10 分钟 | 合上材料，去「卡片」写一张：解释 / 例子 / 连线 |
| 复习 | 5 分钟 | 把「复习」里到期的卡过一遍，讲得出来才算过 |

三个判断标准，都不是"读了几篇"：

- 这周我能**讲清**几个概念？
- 卡片之间多了**几条连线**？
- 有没有一次真的**用上**了？

## 四个标签页

- **今日** — 按日期自动轮换的每日主题（内置 24 天，覆盖科技 / 历史 / 常识 / 思维四类），每次一条，含三个输入方向、三道自测题、一个连线提示
- **卡片** — 你的知识卡，一条一个概念；可增删，支持导出 JSON / Markdown
- **复习** — 间隔重复队列，间隔 1 / 3 / 7 / 21 / 60 / 120 天。讲得出来就拉长，讲不出来打回一天
- **更多** — 备份、导入导出、清空

## 数据存在哪

卡片存在**浏览器的 localStorage**里，不上传任何服务器。

- **换机、换浏览器、清缓存前，先「更多 → 导出备份」。**
- 导出的 Markdown 可以直接丢进 Obsidian / flomo / 备忘录。
- 部署到 GitHub Pages 后，**更新代码不会影响你已有的卡片**——数据在手机上，不在仓库里。

## 关于"随时推荐"

页面内置的内容按日期自动轮换，不依赖任何在线服务。想加新的一批，直接改 `index.html` 顶部的 `DAILY` 数组即可（一条一个对象：`track / title / hook / reads / quiz / link`）。

## 部署到 GitHub Pages

仓库根目录就是站点根目录。推上去后在仓库 Settings → Pages 里选 `main` 分支的 `/ (root)` 即可。

之后每次更新内容，运行：

```powershell
.\publish.ps1 "补充 30 天内容"
```

## 开发者

