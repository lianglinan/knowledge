# 每日知识

一个零依赖的静态网页，每天自动组合 **8 条**来自不同领域的知识，用来把「广泛涉猎」变成能记得住、能用上的东西。

打开 `index.html` 就能用，不需要服务器、不需要联网、不需要构建。

## 内容构成

**10 个领域，60 条，每天抽 8 条**（来自 8 个不同领域，按日期自动轮换）：

| 领域 | 条数 | 关注点 |
|---|---|---|
| 金融 | 6 | 利率、通胀、汇率、杠杆、估值、央行工具 |
| 科技 | 6 | 分布式、密码学、性能物理、投递语义 |
| 行业 | 6 | 供应链、平台经济、产业链、产能周期、定价权 |
| 政策 | 6 | 产业政策、财政货币、央地关系、监管、数据合规、文件体裁 |
| 农业 | 6 | 粮食安全、育种、化肥、农机化、价格形成、气候 |
| 历史 | 6 | 技术传播、制度变迁、帝国的规模成本 |
| 常识 | 6 | 健康指标、睡眠、食物保存、复利、家用安全、概率 |
| 法律 | 6 | 合同、劳动、知识产权、消费、侵权、时效 |
| 心理 | 6 | 认知负荷、延迟满足、归因、从众、损失厌恶、习惯 |
| 思维 | 6 | 机会成本、基础比率、激励扭曲、边际、幸存者偏差、二阶效应 |

每条包含：一个钩子、三个具体输入方向、三道自测题、一个连线提示。

## 为什么是「8 条」而不是「1 条」

因为阅读是碎片化的——你可能早上看一条、午休看两条、晚上再看几条。所以：

- 每天固定 8 条打底，**随时进来都有没读的**
- 每条可以单独展开、单独标「已读」，**退出后进度保留**
- 顶部有进度条和「已读 x / 8」
- 读完了点「换一批」，还有新的组合

## 每天怎么用

| 步骤 | 时间 | 做什么 |
|---|---|---|
| 输入 | 每条 2–3 分钟 | 展开一条，三个输入方向挑**一个**去查，读完再动笔 |
| 输出 | 10 分钟 | 有感觉的，去「卡片」用自己的话写一张：解释 / 例子 / 连线 |
| 复习 | 5 分钟 | 「复习」里到期的卡，讲得出来才算过 |

判断标准不是「读了几条」，而是：

- 这周我能**讲清**几个概念？
- 卡片之间多了**几条连线**？
- 有没有一次真的**用上**了？

## 数据存在哪

卡片和阅读进度都存在**浏览器的 localStorage**，不上传任何服务器。

- **换机、清缓存前，先「更多 → 导出备份」。**
- 导出的 Markdown 可以直接丢进 Obsidian / flomo / 备忘录。
- 更新代码不影响已有卡片——数据在你手机上，不在仓库里。

## 加内容

改 `data.js` 就行，格式：

```js
"领域名": {
  color: "#rrggbb",
  items: [
    { t:"标题", h:"一句话钩子",
      r:["输入方向1","输入方向2","输入方向3"],
      q:["自测题1","自测题2","自测题3"],
      l:"连线提示" }
  ]
}
```

新加一个领域，只要在 `DOMAINS` 里加一个键，页面会自动多一个筛选项。每个领域的条数越多，同一条重复出现的间隔越长。

## 部署

推上去后在仓库 Settings → Pages 里选 `main` 分支的 `/ (root)`。

```powershell
.\publish.ps1 "补充内容"
```

脚本会先跑测试，不通过就拒绝推送。
