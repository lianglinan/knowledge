# 每日知识

一个零依赖的静态网页，每天自动组合 **8 条**来自不同领域的知识，用来把「广泛涉猎」变成能记得住、能用上的东西。

打开 `index.html` 就能用，不需要服务器、不需要联网、不需要构建。

## 内容构成

**26 个领域，156 条，每天抽 8 条**（来自 8 个不同领域，按日期轮转）。

完整轮一遍 **19 天**，且轮完之前**不会出现重复条目**。

| 类别 | 领域 |
|---|---|
| 经济与商业 | 金融、行业、管理、政策 |
| 科学与工程 | 科技、物理、数学、生物、医学、能源、城市 |
| 人文与社会 | 历史、哲学、社会学、传播、语言、艺术、音乐、心理 |
| 制度与规则 | 法律、教育、军事、农业、地理 |
| 方法与常识 | 思维、常识 |

每个领域 6 条，每条包含：一个钩子、三个具体输入方向、三道自测题、一个连线提示。

## 为什么是「8 条」而不是「1 条」

因为阅读是碎片化的——你可能早上看一条、午休看两条、晚上再看几条。所以：

- 每天固定 8 条打底，**随时进来都有没读的**
- 每条可以单独展开、单独标「已读」，**退出后进度保留**
- 顶部有进度条和「已读 x / 8」
- 读完了点「换一批」，还有新的组合
- 顶部筛选条可按领域过滤，今天只想看金融就只看金融

## 选条逻辑

所有条目先按「领域轮询」拍平成一维序列：

```
金融0, 科技0, 行业0, …, 语言0, 金融1, 科技1, …
```

每天的游标前进 8 位，取连续 8 个。这样保证：

1. 任意连续的 8 条**必然来自 8 个不同领域**；
2. 游标步进为 8，整池（156 条）轮完之前**不可能重复**；
3. 换一批、隔天、跨月，都由同一个函数确定，不依赖随机数或网络。

## 每天怎么用

| 步骤 | 时间 | 做什么 |
|---|---|---|
| 输入 | 每条 2–3 分钟 | 展开一条，三个输入方向挑**一个**去查，读完再动笔 |
| 输出 | 10 分钟 | 有感觉的，去「卡片」用自己的话写一张：解释 / 例子 / 连线 |
| 复习 | 5 分钟 | 「复习」里到期的卡，讲得出来才算过 |

判断标准不是「读了几条」，而是：

- 这周我能**讲清**几个概念？
- 卡片之间多了**几条连线**？
- 有没有一次真的**用上**了？

## 数据存在哪

卡片和阅读进度都存在**浏览器的 localStorage**，不上传任何服务器。

- **换机、清缓存前，先「更多 → 导出备份」。**
- 导出的 Markdown 可以直接丢进 Obsidian / flomo / 备忘录。
- 更新代码不影响已有卡片——数据在你手机上，不在仓库里。

## 加内容

改 `data.js` 就行：

```js
"领域名": {
  color: "#rrggbb",
  items: [
    { t:"标题", h:"一句话钩子",
      r:["输入方向1","输入方向2","输入方向3"],
      q:["自测题1","自测题2","自测题3"],
      l:"连线提示" }
  ]
}
```

- 新加一个领域：加一个键，页面自动多一个筛选项。
- 给现有领域加条数：直接往 `items` 里追加，轮转周期自动变长。
- 各领域条数不一致也能跑，只是那几天可能出现同领域的两个条目。

## 部署

推上去后在仓库 Settings → Pages 里选 `main` 分支的 `/ (root)`。

```powershell
.\publish.ps1 "补充内容"
```

脚本会先跑测试，不通过就拒绝推送。
